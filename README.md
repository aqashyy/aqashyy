## 🛡️ Security-Aware Development

Cybersecurity is not my primary profession, but learning its fundamentals
has influenced the way I develop software.

When building applications, I try to think beyond whether something
**works** and also consider:

```text
Can this input be abused?
        ↓
Can this endpoint be accessed without permission?
        ↓
Can a user access another user's data?
        ↓
What happens if someone manipulates this request?
        ↓
Could sensitive information be exposed?
        ↓
What happens if this feature is attacked?
```

This mindset encourages me to consider:

* Authentication and authorization
* Access control
* Input validation
* API security
* Data protection
* Secure database queries
* Session and credential security
* Server permissions
* Secure configuration
* Common web vulnerabilities

I've also explored cybersecurity fundamentals using tools such as
**Kali Linux, Nmap, and Metasploit**, along with basic wireless security
concepts, mainly as part of my personal learning.
